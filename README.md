# Русификатор Ruffy and the Riverside

Неофициальный русский перевод игры [Ruffy and the Riverside](https://store.steampowered.com/app/1002260/) (Steam, версия v1.2.0).

## Что переведено

- **Весь текст:** диалоги и катсцены (724 файла), журнал заданий, реплики NPC, интерфейс, имена персонажей.
- **Картинки с текстом:** «Нажмите любую кнопку», заголовки меню, экраны управления (клавиатура, Xbox, PS5, Switch), обучающие подсказки, таблички в мире игры (ПРОПАЛ, РОЗЫСК, ЛАВКА, КЕПКИ, ОЧКИ).
- **Шрифты:** включена поддержка кириллицы.

Русский язык встаёт на место английского. В меню он называется «Русский».

## Установка

1. Скачайте **`RuffyRus.exe`** со страницы [Releases](https://github.com/DigitalM00N/ruffy-and-the-riverside-rus/releases/latest). Ничего дополнительно ставить не нужно.
2. Закройте игру и запустите `RuffyRus.exe`, выберите **1 — установить**.
   - Игра в Steam находится автоматически. Если не нашлась, установщик попросит перетащить папку игры в окно.
3. В игре: **Настройки → Язык → «Русский»**.

Windows может показать предупреждение SmartScreen: файл не подписан. Нажмите **«Подробнее» → «Выполнить в любом случае»**.

## Удаление

Запустите `RuffyRus.exe` ещё раз и выберите **2 — удалить**. Другой способ — в Steam «Проверить целостность файлов игры».

Оригинальные файлы игры при установке сохраняются в папку `rus_backup` внутри папки игры.

### Установка через Python (для разработчиков)

Нужен [Python 3.10+](https://www.python.org/downloads/). Скачайте репозиторий и запустите `install.bat` (удаление — `uninstall.bat`). Путь к игре можно передать аргументом: `install.bat "D:\...\Ruffy and the Riverside"`.

Собрать exe самостоятельно: `pip install -r requirements.txt pyinstaller`, затем `build_exe.bat`.

## Как это устроено

В репозитории нет файлов игры. Установщик берёт ваши собственные файлы и вписывает в них перевод с помощью [UnityPy](https://github.com/K0lb3/UnityPy).

| Папка | Содержимое |
|---|---|
| `ru/` | тексты перевода (тот же формат, что у игры) |
| `img/ru/` | перерисованные картинки с русским текстом |
| `data/` | индекс ресурсов игры (пути и ID объектов) |
| `tools/build.py` | сборка патча |
| `tools/install.py` | установка и удаление, бэкап |
| `tools/check.py` | проверка формата перевода |
| `TRANSLATION_GUIDE.md`, `glossary_names.md` | правила перевода и глоссарий |

## Ограничения

- Работает только с версией игры **v1.2.0**. После обновления игры перевод может слететь, тогда запустите `install.bat` ещё раз.
- Надписи «RIVERSIDE» на указателях и большие 3D-буквы оставлены как есть: это название и модели.
- Заголовок «Громкость» в игре — общая картинка для английского, французского и португальского. После установки во французской и португальской версиях он тоже будет на русском.

## Поправить перевод

Тексты лежат в `ru/` в том же формате, что у игры. В диалогах переводятся только строки с отступом и варианты ответа `* …`, служебные строки (`!Camera`, имена говорящих и т.п.) не трогаются. Проверить формат после правок можно так: сначала извлечь английские оригиналы из своей игры (`tools/extract.py` → `orig/en`), затем:

```
python tools/check.py
```

Нашли ошибку — откройте issue.
